# 이면 · SIDE B 2.0

마리나라(Marinara Engine)용 개인 확장입니다. Side Story 0.15.9의 새 화면과 기능을 기존 Side-B에 이식했습니다.

## 설치 및 업데이트

마리나라 개인 확장에서 설치 ZIP을 가져오세요. 기존 사용자는 **기존 `이면 · SIDE B` 확장을 업데이트**하세요. 새 항목으로 중복 설치하거나 기존 확장을 삭제하면 확장별 설정 저장소를 이어받지 못할 수 있습니다. 업데이트 후에는 변경된 코드의 권한 승인을 진행하세요.

직접 패키지를 만들 때는 저장소의 `manifest.json`과 `extension.js` 두 파일을 ZIP 최상위에 넣으면 됩니다. GitHub의 전체 소스 ZIP은 설치 패키지와 다릅니다.

## 변경 사항

- 새 작성 화면, 기록 보관함, 시리즈 이어쓰기와 읽기 설정
- 번역 실패 응답 보관, 수동 교정 후 재개
- 인물 핵심정보 추출과 AU 생성, 캐릭터·페르소나로 저장
- 마리나라 연결·프리셋·캐릭터·페르소나·로어북 연동 및 결과로 RP 채팅 만들기
- 생성 준비 중 연속 실행 방지와 중단 버튼
- 창을 닫으면 전체 화면 호스트를 숨기고, 확장 종료 시 화면·이벤트를 정리

기존 `sideB` 설정 키와 `side-b-archive-v1` 보관함을 유지합니다. 기존 프롬프트, 기록, 런처 위치를 이어받습니다.

## 참고 자료 방식

- **본편 연결**: 마리나라가 현재 채팅에 대해 조립한 프롬프트를 사용합니다. 본편 프리셋과 연결된 자료를 따릅니다. 대화 범위도 마리나라 설정을 따르므로 Side-B의 과거 시리즈 기준점으로 자르지 않습니다.
- **직접 선택**: 카드·페르소나·로어북 엔트리와 최근 대화 범위를 직접 고릅니다. 이어쓰기는 메시지 UUID 기준으로 시리즈 시작 이후의 본편 대화가 섞이지 않게 합니다. 키워드 스캔은 기본 키·보조 키·대소문자·단어 경계·정규식을 지원하는 간단한 필터입니다. 마리나라의 벡터 검색, 재귀·확률·게임 상태·시간 조건까지 재현하지는 않습니다. 전체 활성화 규칙이 필요하면 본편 연결을 사용하세요.

토큰 수는 클라이언트 추정값입니다. 모델별 정확한 토크나이저 계산과 차이가 있을 수 있습니다.

## 개발 및 검증

```sh
npm run build
npm test
```

Node.js 22 이상과 Python 3이 필요합니다. 별도 npm 설치 없이 실행할 수 있도록 테스트용 DOM 런타임을 포함했습니다(라이선스: `test-runtime/LICENSE-linkedom`). `src/`를 수정한 뒤 `build.py`로 배포용 `extension.js`를 재생성합니다.

59개 자동 테스트에서 설정·보관함 호환, 주요 화면 렌더링, 생성·이어쓰기, 프리셋 전달, 번역 복구, 중복 실행·중단, RP 채팅 생성, 종료 정리를 검증했습니다. 마리나라 REST/SSE는 모의 응답으로 검증했으며 실제 설치 환경과 실제 모델 호출에 대한 실행 검증은 별도로 필요합니다.
