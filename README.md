# 이면 · SIDE B 2.2

마리나라(Marinara Engine)용 개인 확장입니다. Side Story 0.15.9의 새 화면과 기능을 기존 Side-B에 이식했습니다.

## 설치 및 업데이트

마리나라 개인 확장에서 설치 ZIP을 가져오세요. 기존 사용자는 **기존 `이면 · SIDE B` 확장을 업데이트**하세요. 새 항목으로 중복 설치하거나 기존 확장을 삭제하면 확장별 설정 저장소를 이어받지 못할 수 있습니다. 업데이트 후에는 변경된 코드의 권한 승인을 진행하세요.

직접 패키지를 만들 때는 저장소의 `manifest.json`과 `extension.js` 두 파일을 ZIP 최상위에 넣으면 됩니다. GitHub의 전체 소스 ZIP은 설치 패키지와 다릅니다.

## 2.2 변경 사항

- 업로드된 2.2.0 설치본 반영: 형식별 보조 대화, 강조색·읽기 이동 설정, 이어쓰기 옵션 및 시리즈를 새 RP방으로 옮기는 기능 개선.
- 설치본에서 소스 파일을 동기화했으며 `python3 build.py` 출력이 제공된 `extension.js`와 바이트 단위로 일치합니다.

## 2.1 변경 사항

- **기기 간 보관함 동기화**: 보관함을 마리나라 서버의 확장 저장공간에 압축해 올려 휴대폰·PC에서 같이 봐요. 저장공간은 설정과 합쳐 1MB라, 넘치면 즐겨찾기와 최근 기록부터 올리고 나머지는 만든 기기에만 남아요(설정 › 백업 · 불러오기에서 상태 확인). 삭제도 다른 기기에 반영돼요.
- **긴 글이 앞부분만 보이던 문제 수정**: 마리나라의 보안 정책(CSP)이 읽기 화면 안의 스크립트를 막아 높이를 재지 못했어요. 이제 SIDE B가 바깥에서 직접 재요. 같은 이유로 막혀 있던 PNG 저장·발췌 선택·정규식 치환 표시도 다시 동작해요.
- **깜빡임·스크롤 초기화 수정**: 클릭할 때마다 화면 전체를 새로 그리던 방식을 바뀐 부분만 고치는 방식으로 바꿨어요. 설정창 배경이 사라졌다 다시 뜨지 않고, 스크롤·입력 위치가 유지돼요.
- **참고 채팅 바꾸기**: 왼쪽 위 캐릭터·채팅 이름(휴대폰은 ‘새로 쓰기’ 오른쪽 위 채팅 이름)을 눌러 바로 바꿔요. 바꿔도 열려 있던 화면과 설정창은 그대로예요. 마리나라에서 채팅을 옮겨도 생성 중이면 중단하지 않아요.
- SIDE B에서 글을 쓰다 방향키를 눌러도 마리나라 채팅방의 답변 스와이프·재생성 단축키가 작동하지 않아요. SIDE B가 열려 있는 동안 키 입력은 SIDE B 안에서만 처리해요.
- 시트 바깥(어두운 배경)을 누르면 닫혀요. 프리텐다드 글꼴이 마리나라에서도 적용돼요.
- 마리나라 보안 정책상 HTML 결과의 JS는 SIDE B 화면 안에서 실행되지 않아요. CSS로 만든 탭·펼치기는 동작하고, JS 화면은 파일로 저장해 브라우저에서 열어 주세요.

## 2.0 변경 사항

- 새 작성 화면, 기록 보관함, 시리즈 이어쓰기와 읽기 설정
- 번역 실패 응답 보관, 수동 교정 후 재개
- 인물 핵심정보 추출과 AU 생성, 캐릭터·페르소나로 저장
- 마리나라 연결·프리셋·캐릭터·페르소나·로어북 연동 및 결과로 RP 채팅 만들기
- 생성 준비 중 연속 실행 방지와 중단 버튼
- 창을 닫으면 전체 화면 호스트를 숨기고, 확장 종료 시 화면·이벤트를 정리

기존 `sideB` 설정 키와 `side-b-archive-v1` 보관함을 유지합니다. 기존 프롬프트, 기록, 런처 위치를 이어받습니다.

## 참고 자료 방식

- **본편 연결**: 마리나라가 현재 채팅에 대해 조립한 프롬프트를 사용합니다. 본편 프리셋과 연결된 자료를 따릅니다. 대화 범위도 마리나라 설정을 따르므로 Side-B의 과거 시리즈 기준점으로 자르지 않습니다.
- **직접 선택**: 카드·페르소나·로어북 엔트리와 최근 대화 범위를 직접 고릅니다. 이어쓰기는 메시지 UUID 기준으로 시리즈 시작 이후의 본편 대화가 섞이지 않게 합니다. 키워드 스캔은 기본 키·보조 키·대소문자·단어 경계·정규식을 지원하는 간단한 필터입니다. 마리나라의 벡터 검색, 재귀·확률·게임 상태·시간 조건까지 재현하지는 않습니다. 전체 활성화 규칙이 필요하면 본편 연결을 사용하세요.

토큰 수는 클라이언트 추정값입니다. 모델별 정확한 토크나이저 계산과 차이가 있을 수 있습니다.

## 개발 및 검증

```sh
npm run build
npm test
```

Node.js 22 이상과 Python 3이 필요합니다. 별도 npm 설치 없이 실행할 수 있도록 테스트용 DOM 런타임을 포함했습니다(라이선스: `test-runtime/LICENSE-linkedom`). `src/`를 수정한 뒤 `build.py`로 배포용 `extension.js`를 재생성합니다.

62개 자동 테스트에서 설정·보관함 호환, 주요 화면 렌더링, 생성·이어쓰기, 프리셋 전달, 번역 복구, 중복 실행·중단, RP 채팅 생성, 종료 정리, 화면 패치, 보관함 동기화 병합·용량 맞춤을 검증했습니다. 마리나라 REST/SSE는 모의 응답으로 검증했으며 실제 설치 환경과 실제 모델 호출에 대한 실행 검증은 별도로 필요합니다.
